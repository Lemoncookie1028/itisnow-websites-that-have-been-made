How to Join

For new players confused on how to join - follow these steps in order.

Important: We recommend using Emerald Launcher, not vanilla LCE
  1. Download Emerald Launcher.
  2. Set up the launcher by going through first-time setup. Be sure to set your username - it cannot be "Player".
  3. Select Revelations as your LCE version and download it. Any other version will cause issues in game - choose Revelations.
  4. Press Play in Emerald Launcher and the game should start up.
  5. The server "LapboardMC" should already be in your server list. If not, continue to steps 6–7.
  6. Click Add Server.
  7. Enter the IP address and port from the Connect section.
  8. Once you've added and joined the server, go back to Discord and head to the verification channel.
  9. Enter the same username you used when setting up the launcher. This part matters.
  10. You'll get a confirmation message that your account has been linked, then a DM containing your verification code.
  11. Back in Minecraft, you'll be frozen at first. Press T to open chat and type /verify (your code) - for example, /verify 175829.
  12. If that worked, you'll be able to walk around inside the obsidian box. Type /spawn to head to world spawn.
  13. Have fun! Contact Diamondst or a staff member if you have questions or need help joining.
